Quiz

  1. What does HTML stand for?
    A. Hyper Text Markup Language
    B. Home Tool Markup Language
    C. Hyperlinks and Text Markup Language
    D. Hyper Tool Markup Language

    Answer: A. Hyper Text Markup Language

  2. Who is making the Web standards?
    A. Google
    B. Microsoft
    C. The World Wide Web Consortium
    D. Mozilla

    Answer: C. The World Wide Web Consortium

  3. Choose the correct HTML element for the largest heading:
    A. <heading>
    B. <h6>
    C. <head>
    D. <h1>

    Answer: D. <h1>

  4. What is the correct HTML element for inserting a line break?
    A. <break>
    B. <br>
    C. <lb>
    D. <newline>

    Answer: B. <br>

  5. What is the correct HTML for adding a background color?
    A. <body bg="yellow">
    B. <background>yellow</background>
    C. <body style="background-color:yellow;">
    D. <body color="yellow">

    Answer: C. <body style="background-color:yellow;">

  6. Choose the correct HTML element to define important text:
    A. <important>
    B. <i>
    C. <strong>
    D. <b>

    Answer: C. <strong>

  7. Which character is used to indicate an end tag?
    A. *
    B. /
    C. <
    D. ^

    Answer: B. /

  8. How can you make a numbered list?
    A. <dl>
    B. <ul>
    C. <list>
    D. <ol>

    Answer: D. <ol>

  9. How can you make a bulleted list?
    A. <ul>
    B. <ol>
    C. <list>
    D. <dl>

    Answer: A. <ul>

  10. What is the correct HTML for creating a hyperlink?
    A. <a url="http://www.example.com">Example</a>
    B. <a href="http://www.example.com">Example</a>
    C. <a>http://www.example.com</a>
    D. <link src="http://www.example.com">Example</link>

    Answer: B. <a href="http://www.example.com">Example</a>
